# 5 分鐘演講稿：為什麼做這個緊急急救助手網站

各位老師、同學大家好：

今天我想跟大家分享，為什麼我會做這個「緊急急救助手」網站，以及目前已經完成的成果。

我們每個人都有可能遇到突發狀況。做菜時不小心割傷或燙傷手指、走路扭傷腳踝、流鼻血止不住，甚至更嚴重的情況像是有人噎到、中暑，或是家裡有人因為燒炭而昏迷。這些事情往往發生得很突然，當下我們最需要的，是清楚、簡單、馬上能看懂的處理步驟。

可是現實情況常常是：手機一打開，網路上的資訊又多又雜，有的太專業、有的還互相矛盾，緊急時刻根本來不及慢慢找。再加上很多人其實沒有系統學過急救，遇到狀況時容易慌張，甚至用到錯誤的土方法。

所以我做這個網站的核心想法很單純——**把最常見、最實用的急救步驟，整理成一個一眼就能看懂的參考工具**。

目前網站已經完成十個常見緊急狀況的內容，包括：割傷、燙傷、手指骨折、手腕出血、一氧化碳中毒、心肺復甦術、噎住的哈姆立克法、中暑、流鼻血，以及踝關節扭傷。每一項都用清楚的步驟寫出來，並特別標註什麼時候必須立刻就醫、什麼事情絕對不要做。

在技術上，我使用了純 HTML、CSS 和原生 JavaScript 來製作，沒有額外框架，目的是讓網站輕量、載入快速，而且在手機上也能舒適閱讀。介面採用大卡片設計，點擊後就能看到詳細步驟。整個網站也已經部署到 Cloudflare Pages，不需要登入或下載 App，打開網頁就能直接使用。

我刻意把介面做得非常簡單：大卡片、大字、手機友善。因為真正需要用到的時候，人可能已經很緊張，越複雜的設計越幫不上忙。

當然，我必須強調，這個網站只是**一般急救的參考資訊**，絕對不能取代專業醫療建議。遇到嚴重情況，第一件事永遠是撥打 119。網站的目的是在等待救援或處理輕微狀況時，提供一個可靠、快速的參考依據，減少慌亂與錯誤處理。

做這個專案的過程中，我也重新認識到「預防勝於治療」的重要性，以及把專業知識轉成一般人看得懂的語言，其實是一件很有價值的事。希望這個小小的網站，能在關鍵時刻幫助到需要的人。

以上就是我做這個網站的原因、使用的工具，以及目前已經完成的成果。謝謝大家。
