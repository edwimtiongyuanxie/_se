# 緊急急救助手 (Emergency First Aid Helper)

一個簡單的靜態網站，提供常見突發狀況的緊急處理參考指南。

## 涵蓋項目（共 10 項）

1. 🔪 割傷
2. 🔥 燙傷 / 燒傷
3. 🦴 手指骨折
4. 🩸 手腕出血
5. 💨 吸炭昏迷（一氧化碳中毒）
6. ❤️ 心肺復甦術 (CPR + AED)
7. 😮 噎住（哈姆立克法）
8. ☀️ 中暑
9. 👃 流鼻血
10. 🦶 踝關節扭傷 (RICE)

## 使用方式

直接用瀏覽器打開 `index.html` 即可，無需伺服器。

也可以部署到 Cloudflare Pages、GitHub Pages、Netlify、Vercel 等免費靜態託管。

## 注意

本網站僅供一般急救參考，不能取代專業醫療建議。緊急情況請立即撥打 119（台灣）或當地急救電話。

## 技術

純 HTML + CSS + 原生 JavaScript，無依賴。
