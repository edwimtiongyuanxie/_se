# 緊急急救助手 (Emergency First Aid Helper)

一個簡單的靜態網站，提供常見突發狀況的緊急處理參考指南。

## 涵蓋項目

- 🔪 割傷
- 🔥 燙傷 / 燒傷
- 🦴 手指骨折
- 🩸 手腕出血
- 💨 吸炭昏迷（一氧化碳中毒）

## 使用方式

直接用瀏覽器打開 `index.html` 即可，無需伺服器。

也可以部署到任何靜態託管服務（GitHub Pages、Netlify、Vercel 等）。

## 注意

本網站僅供一般急救參考，不能取代專業醫療建議。緊急情況請立即撥打 119（台灣）或當地急救電話。

## 技術

純 HTML + CSS + 原生 JavaScript，無依賴。
